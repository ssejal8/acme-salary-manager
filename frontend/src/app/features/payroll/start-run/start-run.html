  • One payslip per employee eligible for the period who also holds a salary structure effective on its last day. Someone eligible without a package is skipped rather than given a zero payslip.
  • An employee who left during the month is included for it — eligibility is "joined before the period ends and not gone before it begins", which is broader than "active".
  • The period is taken by the draft. Running it again is refused until this draft is cancelled, and a finalised month cannot be run again at all.
  • Loss of pay is not part of starting a run. Every payslip is computed at full attendance, and unpaid days are applied by recomputing the draft afterwards.
