Grades and CTC bands

A band is what a compensation package is checked against (FR-4.3). Leave a bound blank for "no limit" — blank is not zero, and an unbounded side never rejects a package. Amending a band applies to the next assignment; packages already agreed are a record of what was agreed and are not re-validated.
